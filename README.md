기본적인 배치파일의 작동은 DMA 장치가 PC에 물려있을경우
메인 PC에서 PCIE에 꼽힌것들을 수집해주는것입니다.
그로인해 불법적인 장치를 감지하여 1차적으로 확인이 가능합니다.

단 안티치트 개발에 관심이 있다면 PCIE를 가져오는건 누구나 할수있다는것을 알고있겠죠.
저는 치트개발을 10년이상 해왔지만 더 이상 불법적인일을 하고싶지않아 이 프로젝트를 만들게 되었습니다.

자 이제 현역 개발자라면 DMA를 어떻게 감지해야할지부터 걱정일텐데요.
세줄요약으로 말씀드리자면

PCIe 슬롯 스캔: 게임 시작 시 안티 치트가 PCIe 슬롯을 검사해 DMA 카드 같은 부정 행위 장치 존재 여부를 확인합니다.
성능 영향: 스캔 과정에서 시스템 리소스를 많이 사용해 데이터 전송 속도가 일시적으로 느려질 수 있습니다.
칩셋 검증: 안티 치트 드라이버가 칩셋을 분석하여 변조나 비정상적 패턴을 감지합니다.

이정도라고 볼수있겠습니다.

보통 현재 존재하는 DMA 기기들의 펌웨어는 실제로 동작하는 기기들을 카피해와서 감지를 회피하는데요.
예를들면 Realtek PCIe 2.5GbE Family Controller 이런 기기를 똑같이 복제하여 사용하기도 합니다.
첫번째 대책으로는 PCIE 슬롯을 검사하는것이고 검사한 정보중 똑같은장치가 2개가 있거나
혹은 사용하지않을법한 장치를 분석하는것이 첫번째 대책입니다.

또한 최근 에뮬레이트 방식이 발전해왔기 때문에
단순히 첫번째 방법으로는 간단한 차단밖에 할수없겠지요.

두번째 방법은 IOMMU를 활성화시켜야합니다.
IOMMU를 활성화시에 대부분 DMA 장치들이 작동하지않으며
또한 이 방법도 우회가 가능한 펌웨어들이 있지만

대부분 90%이상의(대부분 IOMMU를 우회하지못함) DMA 사용자들이 첫번째 또는 두번째에서 차단될것입니다.
IOMMU를 우회하는 펌웨어들은 대부분 한화로 50만원 이상의 가격을 지불해야하기 때문에
DMA 사용자 입장에서는 조금 사용하기 꺼려할수있는 금액이 되어버리기 때문입니다.

특히 요즘은 DMA장치외에도 정상적인 제품인척 1PC의 치터들은 ( 예를들어 뱅가드같은것들에서 사용하는 1PC 치팅 )
보통은 커널을 사용하지만 드라이버 서명을 불법이나 합법적으로 구매하여 드라이버에 서명후에 단순히 올리는것으로
우회하고있다는것도 알아야합니다.

다만 뱅가드를 제외한 대부분 안티치트들이 DMA 감지에 성과가 없다는걸 알고있고.
EAC정도가 DMA 감지를 시작한것 같지만 기본적인 1PC 탐지도 제대로 작동하지않고 bypass가 쉽다는것은 대부분 치트 개발자들이 알고있기에.
조금이라도 보탬이 되면 좋겠다는 생각에 이 글을 남겨봅니다.

참고로 보통 DMA 사용자들은 FUSER와 KMBOX , 아두이노 , MAKCU등을 사용하기 때문에
꼭 DMA가 아니더라도 다른기기감지도 같이 해준다면
게임보안이 조금더 나아질꺼라 생각합니다.
